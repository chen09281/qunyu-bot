# 后台交互逻辑修复（2026-10-29）

本次修复覆盖设置保存、状态刷新、聊天分页、浏览器导航和订阅预览。

- 白名单、签到、订阅设置保存时保留提交之后的输入。订阅编辑器切换对象后，旧保存响应不会清空新草稿；新增来源保存期间的继续编辑会关联到已创建来源，避免再次新增。
- 轮询只更新没有修改的表单字段。签到和订阅设置遇到同一字段被服务器与本页同时修改时，保留本页内容并提示冲突；可放弃本页草稿，恢复服务器设置。
- 保存前发出的配置或插件状态读取，在写入期间或写入完成后返回时不再覆盖新状态。退出登录后的迟到保存响应也不会恢复白名单。
- 聊天页刷新最新记录时，若与已有记录之间存在缺口，按消息游标补读直到衔接；群之间的数据库 ID 无需连续。切换群后丢弃迟到页面。
- 普通导航增加浏览器历史，首次地址同步和旧地址纠正替换历史。浏览器后退/前进会同步页面及插件详情。
- 管理接口有独立请求超时：普通接口 30 秒，平台登录相关接口 90 秒，模型测试和卡片预览 120 秒，手动订阅检查 300 秒。超时会释放按钮并提示先刷新确认结果。模型后台实际请求的 Token 与超时“无上限”选项保持原有语义。
- 未配置模型密钥仍可进入后台并启用链接解析、签到和订阅。模型问答保持静默，不产生失败任务；定时聊天等待密钥，页面显示待配置状态。权限校验与群/私聊白名单继续生效。
- 订阅预览在独立弹窗中展示最新内容的实际卡片；使用现有渲染器，仅准备卡片，不准备视频及原图聊天记录，不发送 QQ 消息。关闭后恢复原按钮焦点，迟到响应不会重新打开弹窗。

验证包括异步延迟响应、输入继续编辑、跨页记录补齐、取消/超时、插件预览无发送副作用的自动测试，以及使用模拟数据的浏览器交互复核。


## 方案 C：轻二次元工作台

- 主色改为雾蓝与淡紫，保留红色错误、黄色提醒和绿色连接成功等状态色。页面正文、聊天正文与操作按钮字号提高；小屏输入框保持 16px。
- 后台标识、登录页与浏览器图标使用星辉主题 SVG；概览和插件入口采用爱弥斯角色立绘，素材随前端本地提供，不依赖外部图片请求。来源和权属见 `docs/artwork-sources.md`。
- 插件设置改为独立二级页面，保留原来的 `#plugins/...` 地址；支持浏览器后退和面包屑返回。成员签到记录仍是签到的下一级，订阅预览继续用独立弹窗。
- 订阅默认展示按群分类的列表，添加／编辑与推送设置分开显示。游戏快捷入口和使用指令默认收起；每个来源的匹配解释、原始地址和诊断耗时放入「来源与运行详情」，异常提示保留在列表。
- 共享来源在操作按钮前明确提示影响的群数量；「取消订阅」仍只作用于当前群。
- 模型设置分为接口与模型、回复与人格、能力开关、响应规则。分类间保留草稿，底部显示保存状态、保存与撤销操作。隐藏分类中的必填项验证失败会自动切换并聚焦该字段。

- 统计仍为本次服务运行统计；本次未增加日统计，也未调整推送、模型请求、权限及数据存储行为。
