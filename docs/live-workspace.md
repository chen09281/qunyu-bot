# DS 实时工作空间与统一白名单

## API 超时无上限

在「模型与回复 → 模型切换 → 响应规则」点击 API 超时旁的「无上限」，再保存配置。开启时不创建模型请求的本地倒计时；关闭后恢复已保存的 5–180 秒数值。升级默认保留 180 秒与原有数字，新增开关默认关闭，不会重置 Token、模型或授权配置。

接口、网络代理与服务商自己的超时仍有效。机器人暂停、群内 DS 关闭、移出白名单或关闭服务时，在途模型请求仍会取消；无数据返回时也会每秒检查授权。搜索、网页与图片读取、模型列表和 QQ 上传发送沿用独立的短超时。

## 查看 DS 实时

在工作空间左侧进入「DS 实时」，每秒刷新。左侧选择一条任务，可查看问题、群聊或私聊来源、模型、处理阶段、接口返回的思考与回答预览。普通问答、免 @ 续聊、定时问候与后台模型测试都可显示；签到和订阅不会虚构模型任务。

请求使用 [DeepSeek 的流式响应格式](https://api-docs.deepseek.com/api/create-chat-completion/)，按 `reasoning_content`、`content` 和工具调用的实际分片更新。兼容忽略流式参数、只返回 JSON 的服务，但只能在完整结果到达后展示。未开启思考或接口不返回思考时，显示“未返回可展示的思考内容”，不推测或伪造模型内部过程。

回答预览不代表 QQ 已发送；任务进入“已发送”才表示 OneBot 返回成功。生成文档时会显示撰写、排版、发送阶段；最终答案和聊天记录仍沿用现有清理、字数与文件规则。中断且未收到结束标记的流不会作为完整答案发送，工具调用参数仍需原有文档校验。

流式响应逐片消费，不再以累计传输的 2 MiB 限额截断长思考；重复的协议字段、心跳和已消费的思考不会占用最终答案的缓存额度。仍保留内存保护：单个 SSE 事件最多 2 MiB，累计保存的回答与工具参数最多 8 MiB；兼容的完整 JSON 响应最多 16 MiB。超过这些限制会停止请求并明确提示具体原因，不会发送不完整的答案或文档。这些是接收缓存保护，不会修改已保存的输出 Token、超时和“无上限”开关。

实时接口要求现有管理员登录，并设置禁止缓存。普通状态接口和运行日志不携带思考；思考不发送到群聊，也不写入聊天数据库。仅在本次进程内保留最近最多 30 项，单项问题最多 20,000、思考 30,000、答案 20,000 字符；达到展示上限时标明截断，不影响完整响应的后续处理。列表只返回简要问题，正文仅返回当前选中任务，避免每秒重复传输全部正文。退出登录后清除页面数据；服务重启后没有旧的实时记录。

## 统一白名单

群聊和私聊管理统一归入工作空间的「白名单」，通过两个页签切换。各自仍分别保存，开关与权限含义不变；切换页签保留未保存草稿。新入口为 `#whitelist/groups` 与 `#whitelist/private`，旧的 `#groups`、`#private` 地址兼容跳转。模型响应规则、插件与概览中的授权入口也会进入相应页签。
