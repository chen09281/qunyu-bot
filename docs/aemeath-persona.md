# 爱弥斯 · 星辉同伴

## 选择性格与语气

在「模型与回复 → 回复与人格」开启角色性格，选择「爱弥斯 · 星辉同伴」并保存。群聊、白名单私聊、定时问候和免 @ 续聊沿用所选性格。可切回蓝色大肥鱼，或关闭角色性格只使用自定义提示词。更新不会更换已经保存的角色。

文字语气强调轻快、亲近、自然停顿与带笑意的转折；使用问候、分享、互怼、安慰、故障排查等多种示例。此次按用户选择不添加拔网线、掉包、缓存等赛博口癖，不改变声音或增加 TTS。

## 锐评强度与频率

魔丸模式为用户要求的群聊改编，不属于官方设定。关闭魔丸模式后保留正常爱弥斯语气。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 日常锐评强度 | 2 · 阴阳 | 0 关闭 / 1 俏皮 / 2 阴阳 / 3 魔丸 / 4 火力全开 |
| 主动要求锐评时 | 3 · 魔丸 | 用户明确说「锐评」等请求时直接使用此强度，不经过随机抽样 |
| 日常触发机会 | 10% | 程序逐次抽样，抽中后模型仍需判断是否适合互怼；不是保证每十条怼一次 |

认真求助、情绪低落或明确不喜欢时收手，自动定时问候关闭锐评。代码在当前携带上下文中识别停止玩笑的偏好；关闭记忆、开启新话题或超出历史范围后不能保证保留此偏好。需要长期禁用时使用后台开关。比赛锐评不得从输赢推断未知比分、操作或淘汰情况。

每条新会话记录保存人格版本。切换人格后，旧人格回复作为明确标记的历史参考资料传入，不再作为当前助手口吻示例；原始聊天记录、任务事实和用户问题保留。旧记录仅新增字段，不删除数据。

## 人格资料卡：头像与群名片

资料卡位于同一页面，设置独立保存。角色先在模型配置中保存，随后才能操作该角色头像。

- **搜索 / 换一批头像**：使用已有 DeepSeek 搜索能力（若配置），爱弥斯另有已核实的角色资料来源；由当前识图模型判断人物和头像裁切范围。每个人格缓存最多三张 512×512 PNG，可选择其中一张。
- **内置立绘备用**：爱弥斯联网候选不可用或未配置识图模型时，使用当前版本随附、已核实的爱弥斯立绘并标注来源。其他角色无可用候选时保留 QQ 原头像并显示失败。蓝色大肥鱼是项目原创设定，搜索按蓝发、鱼尾少女特征匹配，并非另一个游戏的官方角色。
- **上传头像**：支持 PNG、JPEG、WebP、GIF，最多 6 MiB。服务端解码、限制像素并生成静态方图；GIF 只使用首帧。手动上传不要求模型审核，裁切不满意可先上传自己裁好的方图。
- **应用头像**：明确提交到 QQ。QQ 头像是账号全局共用的；客户端缓存可能延迟更新，界面不会仅凭接口成功声称所有客户端已经刷新。
- **切换人格时自动更新头像**：默认关闭。开启并保存后立即同步；后续切换人格优先复用该角色已选图片。已成功提交的同一头像不重复上传，手动「应用头像」可以强制重试。
- **同步机器人群名片**：默认关闭。选择白名单内的目标群，填写例如 `{name}｜星辉在线` 的模板并保存。只修改当前登录机器人的群名片，不修改群名称、群头像或其他成员。角色名自动替换 `{name}`。
- **重试名片同步**：对目标群检查当前名片，已一致的群不重复修改；每群显示确认、未确认或失败状态。修改后重新读取群成员信息核对。

角色、群白名单或连接配置变化会使旧任务失效。已经发往 QQ 的单次请求无法撤回，界面会提示未完成；后续自动同步按最新配置执行。头像或某个群失败不撤销人格，也不阻止其他群处理。服务重启不会静默重发未确认的修改，需在后台检查后重试。

搜索、识图、裁切和 QQ 同步都有超时与并发限制，图片下载沿用公网地址校验与大小限制。上传文件、候选图、来源和运行状态存于 `data/persona/identity.json`，不提交 Git。所有接口要求后台管理员登录和同源校验，没有向普通群成员或语言模型开放改头像、改名的工具。

## 试聊与验证

「生成试聊」使用实际配置的模型和已保存性格，不搜索、不生成文件、不发送 QQ，也不写入聊天记录；会消耗模型用量。保存性格或强度后再试聊。前端自动刷新不清除试聊结果和未保存的联动草稿。

人格采用请求提示词与上下文处理，不训练模型权重。真实模型会存在语气波动，不能保证每次完全还原角色。此次本地验证包含实际模型试聊、头像处理、配置/权限/切换取消回归以及模拟 QQ 的界面操作；未修改真实 QQ 头像或群名片。
