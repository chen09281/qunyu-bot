# 私聊 DS 与白名单

管理员在后台「白名单 → 私聊白名单」输入允许使用的 QQ 号，点击「添加到名单」，最后点击「保存私聊白名单」。可添加最多 500 个账号；只添加不保存不会生效。移除账号后也需要保存。切换群聊和私聊页签不会丢弃各自未保存的草稿，原来的 `#groups`、`#private` 地址会转到合并后的相应页签。

白名单成员加机器人好友后，直接私聊提问即可，无需 @。可发送图片、引用同一私聊中的图片，或请求「生成一份 Word 文档」「把上面的内容导出为 PDF」；文件会发送到本人私聊。图片识别和文档功能仍需在「模型与回复」中开启，且所选模型应支持相应能力。

群聊和私聊独立授权：加入私聊名单不会开通所在群，也不要求该账号已在授权群中。私聊名单为空时，普通私聊保持静默，不调用模型。已有配置升级后默认空名单，由管理员手动添加。

私聊沿用当前模型、联网搜索、识图、文档、回复长度和冷却设置。每位用户的私聊与各群对话分别保存上下文；后台「聊天记录」和「运行日志」会标明私聊及 QQ 号。未授权私聊不会记录内容，也不会创建模型会话。聊天记录和管理员设置保存在数据目录，重启后保留。

后台「聊天记录」将同一机器人在同一群的对话合并为一个蓝色群聊窗口，私聊按好友展示为紫色窗口，均带文字类型标记。每条提问和回复显示北京时间（UTC+8，精确到秒），群消息标明成员昵称、QQ 号，机器人消息标明回复对象。搜索成员昵称或 QQ 号可找到所在群的完整记录；「查看更早的消息」继续加载历史。同一成员在不同群、私聊与不同机器人之间的模型记忆仍隔离。

移除并保存授权后，排队请求会取消，生成中的结果会在下一次处理或发送前检查授权，不再继续发送。已经发送的消息和历史记录仍保留。在「聊天记录」选择群成员后点击「新话题」，仅重置该成员在当前群的上下文；私聊直接点击「新话题」。历史记录保留。

`/签到` 系列指令优先由签到插件处理，沿用签到自己的群授权和账号绑定规则，不受 DS 私聊白名单控制；绑定凭据不会作为模型消息。分享链接自动解析仍用于群聊；授权私聊中的链接作为 DS 提问处理，B 站视频总结可直接发送链接和总结要求。

如果没有收到回复，先检查 QQ 在线状态、机器人总开关、API Key、私聊白名单是否保存及冷却时间，再查看运行日志。文件发送还取决于 QQ 好友关系、OneBot 文件接口和共享媒体目录。
