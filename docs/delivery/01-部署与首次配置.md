# 首次配置

## 启动教程 · [Windows](启动-Windows.md) ｜ [macOS](启动-macOS.md) ｜ [Linux](启动-Linux.md)

先按对应系统教程启动服务，再在浏览器打开后台。下列步骤适用于 v1.1.0，桌面与手机后台操作相同。

## 创建管理员

全新安装首次打开会显示「创建你的管理员账号」，没有默认账号和通用密码。

1. 设置 3–64 个字符的账号，可用文字、数字、下划线、点、@、短横线。
2. 设置至少 8 个字符的密码，并再次确认。
3. 点击「创建账号并继续」，系统保存密码哈希并自动登录。
4. 绑定自己的 DeepSeek API Key；仅缺少 Key 时要求绑定。

管理员创建后初始化入口关闭，刷新页面或重启服务不会重置账号。已有数据目录时直接使用原账号，已保存的 API Key 会跳过绑定步骤。

## 登录 QQ 与授权群

1. 进入「QQ 连接」，检查 NapCat 状态并获取二维码。
2. 用手机 QQ 扫码并确认登录，检查后台显示的 QQ 号、昵称与在线状态。
3. 在「群聊白名单」添加允许工作的群号，按需开启「调用 DS」「解析视频」并保存。

空白名单时不处理群消息。只有授权群内 @ 机器人的提问进入模型会话；社交链接识别无需 @，也受授权群开关控制。

## 配置模型与链接解析

1. 在「模型与回复」展开模型设置，刷新当前 API Key 可用模型，选择模型并保存。
2. 按模型能力开启深度思考、联网搜索和图片识别，调整思考强度与上下文选项。
3. 在「插件」中点击「链接解析」卡片，在弹出的详细设置中配置媒体大小、时长与超时。B 站推荐扫码登录，使用哔哩哔哩 App 确认；服务器默认每 6 小时检查登录态，按需续期。抖音选择「扫码登录抖音」，使用抖音 App 扫码并确认，Cookie 自动保存，无需复制浏览器登录态；其他平台按页面教程配置自己的 Cookie。
4. 在「运行概览」启用机器人，在授权群中 @ 提问或发送分享链接。
5. 开启「联网搜索与找图」后，可在授权群中 @ 机器人说「找一张猫的图片」；系统会读取相关网页，选择可用图片并发送。找图是搜索已有图片，不是生成新图；来源网站不可访问时会说明失败原因。
6. 在「聊天记录」查看分用户会话；在「运行日志」点击整条记录，查看收到的消息、回复内容、是否调用 DeepSeek 和 Tokens。

管理后台、QQ、B 站与抖音分别登录。平台强制下线或要求验证时仍需重新扫码。

## HTTPS 与访问配置

默认服务使用 HTTP。已有 HTTPS 反向代理时，将 Ubuntu 的 `UBUNTU_BIND` 设为 `127.0.0.1`，同时设置 `UBUNTU_COOKIE_SECURE=true`、`UBUNTU_PUBLIC_ORIGIN=https://实际访问地址`，再重新部署。

macOS 一体化使用 `.env` 中的 `BOT_BIND`、`COOKIE_SECURE` 和 `PUBLIC_ORIGIN`。HTTP 下保持安全 Cookie 选项为 `false`。HTTPS 证书与代理需要另行配置。

运行数据与登录凭据保存在 `data/` 或自定义的数据路径。维护和备份方法见 [运行维护与问题排查](02-运行维护与问题排查.md)。

## 平台 Cookie 加密配置

在 `.env`（Ubuntu 使用 `.env.ubuntu`）中设置 `DATA_ENCRYPTION_KEY` 后，机器人新保存的平台解析 Cookie 会加密落盘。该变量只用于平台 Cookie；签到凭据一直使用独立的 `data/checkin/key` 加密。

修改变量后，按部署方式重新创建机器人容器加载配置：

```bash
# 通用 Docker
docker compose up -d --no-deps --force-recreate qq-bot

# macOS / 本机一体化
docker compose -f compose.integrated.yaml up -d --no-deps --force-recreate qq-bot

# Ubuntu
sudo docker compose --env-file .env.ubuntu -f compose.ubuntu.yaml up -d --no-deps --force-recreate qq-bot
```

仅执行 `restart` 不会更新容器环境变量。已有明文 Cookie 不会自动迁移，需在后台重新保存或重新扫码才会加密。迁移已有加密 Cookie 时需沿用原密钥；更换或清空密钥会使旧密文无法读取，需重新登录对应平台。请单独备份密钥，数据目录的加密备份不包含 `.env` / `.env.ubuntu`。
