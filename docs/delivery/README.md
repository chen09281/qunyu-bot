# 群屿 · QQ 群助手

**v1.1.0** · 群聊 AI 回复、社交链接解析和可视化管理，一套后台即可完成配置。

群屿通过 NapCat / OneBot v11 接入 QQ，使用 DeepSeek API 回答群聊问题。支持桌面和手机访问的 Vue 管理后台，适合个人群助手与小型社群。

## 启动教程 · [Windows](文档/启动-Windows.md) ｜ [macOS](文档/启动-macOS.md) ｜ [Linux](文档/启动-Linux.md)

点击上方系统名称查看完整安装与启动步骤。首次运行前，准备一个 QQ 账号和自己的 DeepSeek API Key。

| 系统 | 推荐运行方式 | 启动命令 | 后台地址 |
| --- | --- | --- | --- |
| Windows | Docker Desktop + WSL2 Ubuntu | Ubuntu 终端执行 `sudo bash ubuntu.sh deploy` | `http://127.0.0.1:3080` |
| macOS | Docker Desktop + Node.js | 终端执行 `npm run deploy` | `http://127.0.0.1:3080` |
| Linux / VPS | Docker Engine + Compose | 终端执行 `sudo bash ubuntu.sh deploy` | `http://服务器IP:3080` |

命令均在包含 `package.json`、`ubuntu.sh` 的应用目录执行；若解压后外层有 `应用/` 文件夹，请先进入该文件夹。完整运行推荐 Docker，自动启动机器人后台和 NapCat，并安装链接解析依赖。

## 功能特色

- **按需回答**：只在授权群中被 @ 时调用 DeepSeek；群白名单可分别控制 AI 回复与视频解析，空白名单时保持静默。
- **独立聊天记忆**：按「群号 + QQ 用户」保存上下文，不同群、不同提问者各有独立会话；后台可查看历史提问与回复。
- **灵活模型配置**：从当前 API Key 获取可用模型，切换并显示已保存模型；按模型能力设置深度思考、思考强度、联网搜索和图片识别。
- **联网搜索发图**：@ 机器人找图片、立绘或壁纸，读取搜索网页并选择相关图片发送到群聊；同一用户可继续追问「发出来」。每次最多 3 张、单张最多 6 MiB，沿用已绑定的 DeepSeek API Key 与联网搜索开关。
- **分享链接自动解析**：未 @ 机器人时，自动识别哔哩哔哩视频 / 动态、抖音、小红书等平台链接；图文生成预览卡片，抖音图集用一条普通多图消息发送原图，其他多图合并为聊天记录，视频下载后发送到群内。@ 机器人并附上链接时，只调用 DeepSeek 回答，不触发自动解析。
- **平台扫码登录**：B 站扫码后按需自动续期；抖音使用官方扫码入口，确认后自动保存 Cookie，每 6 小时检查并同步有效登录中的 Cookie。其他平台可按页面教程导入 Cookie。
- **清晰的运行记录**：显示是否调用 DeepSeek、输入 / 输出 Tokens、耗时和群号；点击整条日志查看收到的内容与实际回复。
- **手机与桌面管理**：查看 QQ 在线状态、扫码登录、管理授权群、配置模型、查看聊天记录与运行日志。
- **自主设置账号**：首次打开创建自己的管理员账号和密码，无默认账号；已有账号和 API Key 时自动跳过相应初始化步骤。登录时默认保持登录 30 天，关闭浏览器或重启服务后可继续使用；退出登录或修改密码会撤销相应登录态。

模型功能取决于所选接口和模型能力；平台解析受登录态、网络、平台风控及媒体大小限制影响。平台要求重新验证时，需要再次登录。

## 第一次使用

1. 按对应系统教程启动服务，打开后台地址。
2. 创建管理员账号（3–64 个字符）和密码（至少 8 个字符）。
3. 绑定 DeepSeek API Key。
4. 进入「QQ 连接」，用手机 QQ 扫码确认，检查在线状态。
5. 在「群聊白名单」添加允许使用的群号，保存各群功能开关。
6. 在「模型与回复」选择可用模型并保存；进入「插件」点击「链接解析」卡片，按需配置平台登录态；卡片开关可直接启停解析。
7. 在「运行概览」启用机器人，在授权群中 @ 提问或发送分享链接。

完整操作见 [首次配置](文档/01-部署与首次配置.md)。管理后台、QQ 和社交平台分别登录，后台管理员账号不用于平台登录。

## 数据保存

管理员、API Key、Cookie、QQ 登录态和聊天记录保存在 `data/`；自定义路径时以实际配置为准。升级前先停止服务并备份，保留原数据目录、`.env` / `.env.ubuntu`。重新启动不会清空聊天记录或重置账号。

密码使用 scrypt 哈希存储。默认后台为 HTTP，公网使用时可配置 HTTPS 反向代理，并按实际地址设置安全 Cookie 与访问来源。
