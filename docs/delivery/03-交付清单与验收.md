# 交付清单与验收

版本：1.1.0。交付日期：2026-10-18。

## 交付范围

提供可解压使用的应用目录和 ZIP 压缩包，包含：Vue 前端源码及构建产物、Node 后端、Python 解析器、Ubuntu / Mac Docker 部署文件、环境配置示例、固定依赖清单、回归测试、版本记录及维护文档。

`VERSION.json` 记录版本、构建时间和源码提交；`SHA256SUMS` 记录逐文件 SHA256；外层 ZIP 另附 `.sha256`。重新压缩会改变 ZIP 的摘要，不能据此认定源码变化。

明确不包含：实际 `data/`、账号或密码、API Key、平台 Cookie 和刷新令牌、QQ 登录会话、聊天数据库、真实 `.env` / `.env.ubuntu`、SSH 私钥、个人 Git 配置或 Git 历史。`*.example` 仅为配置示例。

## 安装验收

在独立新目录按部署文档启动，使用新数据目录完成以下检查：

- 后台 `/health` 返回 `ok:true`，页面可打开。
- 第一次打开显示创建管理员；账号及密码由接收方自行设置，没有默认预填。
- 无效账号、过短密码或两次密码不一致不能创建；创建成功后可登录，初始化入口关闭。
- 重启后使用相同账号登录；改密保留用户名，已有账号不能通过初始化接口被覆盖。
- 缺少 API Key 时引导绑定；已有 Key 时进入工作空间。
- 手机窄屏可展开菜单、填写表单、打开日志详情和查看独立用户聊天记录。

## 接入验收

完成自己的真实账号配置后再检查：

- QQ 扫码后显示在线状态，群白名单保存后生效。
- 白名单群中 @ 机器人得到回复；普通文字、未授权群不调用模型。
- 运行日志显示 DS 是否调用、Token 用量和消息 / 回复详情。
- 同群同用户的下一轮提问携带成功的上下文，不同用户隔离。
- 配置有效的平台登录态后，分享可访问的图文 / 视频链接，验证卡片、合并图片或视频发送。
- B 站扫码后显示登录有效、自动续期可用和下一次检查时间。页面关闭后由服务器定时执行。

源码回归可在 `应用/` 执行：

```bash
npm ci
npm test
```

测试使用模拟 DeepSeek / OneBot 等接口，不消耗真实模型额度或向群发送测试消息。Python 部分有媒体依赖时执行完整验证，缺少 FFmpeg / Pillow 等时对应测试可能跳过。

## 使用边界

交付包不是离线系统镜像，不附带 Docker Engine、Node.js 安装包、已构建 Docker 镜像或付费 API 额度。首次构建、依赖安装和实际功能接入需要相应网络。

默认服务为 HTTP，未签发证书，也未自动配置公网 HTTPS。需要 HTTPS 时使用自己的反向代理和证书，并同步调整 Secure Cookie 与 PUBLIC_ORIGIN。

平台规则、风控、登录失效、版权或内容权限可能影响解析；无法保证所有链接、账号和网络环境都可用。Token 以实际 API usage 返回为准，平台搜索可能独立计费。B 站自动续期不能恢复被强制注销的会话，遇到验证时仍需人工扫码。

部署脚本只管理本 Compose 项目的容器，不附带云账号、域名账户、VPS 管理权限或自动推送部署流程。交付后由接收方自行保管管理员密码、平台登录态及备份。
