# 联网搜索与飞行雪绒点歌

## 联网搜索

在「模型与回复 → 能力开关」开启联网搜索；在模型库中为模型勾选「允许此模型联网搜索」，保存后通过功能下拉框分配。

- Sol / OpenAI Responses：调用当前接口的原生 `web_search`，可以与文档生成工具一起使用。是否真正搜索，以接口结果为准；返回的来源链接保留在 QQ 回答中。
- Kimi：官方 `api.moonshot.cn` / `api.moonshot.ai` 地址使用 Kimi 独立搜索、网页抓取接口，搜索结果作为外部参考资料送入模型。
- Chat Completions 兼容接口：存在原有 DeepSeek 密钥时，可复用原有 DeepSeek 搜索来源。模型和搜索的凭据互相独立。
- 关闭联网总开关或模型自己的搜索开关后，不搜索。主动定时问候不会调用搜索。

接口账号必须拥有相应模型与搜索权限；兼容服务需自行支持原生搜索工具。测试使用模拟接口覆盖协议、工具组合、结果归一化、状态及来源；未使用真实密钥调用收费接口。

官方说明：[OpenAI Web Search](https://developers.openai.com/api/docs/guides/tools-web-search)、[Kimi 搜索接口与使用建议](https://platform.kimi.com/docs/guide/best-practices-for-web-search)。

## 群聊点歌

授权群成员 @机器人并发送：

```text
播放 纸飞机
播放 Brand New Sky
播放飞行雪绒的歌
飞行雪绒歌曲列表
```

指定歌名时发送该曲，未指定歌名时随机选择；目录请求只发清单。支持星轨消逝之夜、碎花、纸飞机、靛青宇宙、Deadline Disco、Brand New Sky、星炬不熄、小小奇迹。`星轨消逝之夜` 是专辑入口，在线目录中默认选择其中的《小小奇迹》，显示实际曲名。

普通无 @ 的群聊和持续聊天不会自动点歌。机器人总开关、群白名单及该群的模型回复开关仍需启用；白名单私聊也可以点歌。点歌不需要模型密钥，不调用模型，不写入聊天记忆。

群中先显示歌名及“高潮片段／试听片段／完整版”，再发送可点击播放的 QQ 语音。默认只发送约 30 秒片段；用户说“播放纸飞机完整版”“整首播放飞行雪绒的歌”时请求整首，否定完整版仍使用默认片段。只有试听音源时会明确告知暂无法播放完整版。

## 音源

优先使用管理员准备的本地音源：

```text
data/music/tracks/纸飞机.mp3
data/music/tracks/Brand New Sky.mp3
```

文件名需与点播目录中的中文／英文名称一致。支持 mp3、m4a、wav、flac、ogg；单文件不超过 80 MiB；完整版不再按固定 8 分钟截断，在线音源仍遵守链接解析的时长和大小限制。目录和文件不能使用符号链接。

未配置本地文件时查询 Apple 国际公开音乐目录，匹配曲名和歌手，再读取其公开预览音频。在线源可能仅提供片段，中文歌名会匹配官方英文元数据；星炬不熄优先匹配中文版本，不使用伴奏或同名歌手作品。完整版优先使用本地完整音源或目录中已有的 B 站音源，无法从公开试听恢复完整版。公开试听按所在网络与平台提供范围可用，不保证每首永久可用。

高潮位置通过 `data/music/segments.json` 记录，键使用点播目录的准确曲名；`start` 是完整音源中高潮开始的秒数，`duration` 默认 30 秒（允许 5–60 秒）。文件不提交 Git，修改后下一次点播生效：

```json
{
  "准确曲名": { "start": 60, "duration": 30 }
}
```

示例时间仅说明格式，不代表某首歌的真实高潮位置。仅完整音源使用标注的时间；Apple 公开试听本身已是片段，不再套用完整音源的偏移。未标注的完整音源暂播开头 30 秒并明确标为“试听片段”，不冒充高潮。M4A 和其他格式都会经过同一裁剪流程。专辑入口可以复用实际曲目的标注。

临时输出位于 `data/media/music/`，映射到 NapCat 的共享媒体挂载。发送确认后清理，发送未确认时延迟清理；停止服务会取消下载与转换。需要 ffmpeg（VPS 镜像已包含），也可以设置 `FFMPEG_PATH`。

## 音乐点播插件页

后台「插件 → 音乐点播」提供独立开关、歌手分类、中文／英文／别名搜索和「检测全部音源」。当前八个入口归类到飞行雪绒；专辑入口会注明实际选曲。检测只读取音源目录，不向 QQ 群发送消息，匹配状态与实际播放结果分开显示。

现在支持 `播放`、`演奏`、`点播`、`放一下`、`放一首`、`来一首`、`来首`、`听听`、`想听`、`唱一首` 等动作。英文名称、极限迪斯科、新世界的天空，以及“星炬不息”的常见写法均可匹配。否定或停止指令不点歌。

歌手查询结果未包含目标曲目时，会单独按曲名和歌手回查，仍保持精确的曲目与歌手匹配，防止使用同名歌曲或伴奏。音源状态与最近播放结果保留在当前进程中；重启后可重新检测。
