# 用量归属、账单推送与故障处理

## 群聊和用户用量

“模型与回复 → 用量与计费”顶部增加群聊与成员排名，按北京时间日期及 API 渠道筛选。群聊、私聊、定时发言和后台测试分开归属，联网搜索/抓取记在触发它们的会话与成员下。金额按请求时单价记录，美元沿用账单页的参考汇率折算为人民币；这些归属估算不改变官方基准金额。

启动时从聊天数据库一次性补录旧会话的 Token 与次数。历史已有同日归属记录时保守跳过，避免重复。没有输入输出、没有当日已计价模型数据或模型对应多个服务商时，不猜测费用。历史排名可能不完整，不代表官方账单中的全部消费。

## 每周账单邮件

进入“QQ 连接 → QQ 掉线通知与每周账单邮件”，填写 SMTP 主机、端口、账号、授权码、收件邮箱与北京时间发送时刻，再启用“每周发送账单邮件”。默认每周一 08:00 发送上周一至周日的费用、Token、请求次数和 Token 用量最多模型。邮件同时包含排版后的 HTML 和纯文本内容，不再通过 QQ 私聊发送，无需 Chromium 或 QQ 在线。

账单与掉线邮件共用邮箱配置，可分别开关。旧的每日周期自动迁移为每周，旧 QQ 收件人字段移除。程序每分钟检查，计划时刻后 15 分钟内可补发，超出窗口不补发；每个周期仅尝试一次，失败时保留失败状态，避免邮件服务已收到但连接超时导致重复。SMTP 未配置时不会占用本周发送机会。费用来自本地调用明细估算，不将官方总额快照虚构为逐日账单。

## QQ 掉线邮件

在“QQ 连接”同一面板配置 SMTP 主机、端口、账号、授权码、收件邮箱及后台外网地址，再开启邮件告警。465 通常勾选隐式 TLS；其他端口使用 STARTTLS，证书验证保持开启。连续三次每分钟探测未在线后通知一次，包括后台的 QQ 连接页面入口；未知连接状态明确标注为未知。发送失败至少隔五分钟重试，恢复在线后允许新一轮告警。SMTP 授权码不回显，修改 SMTP 主机、账号或连接方式后需重新填写授权码。

此功能只检查状态，不重启 NapCat、不刷新二维码、不修改登录数据。未配置 SMTP 或关闭时不发送邮件。

## API 自动故障切换

“模型与回复 → 模型库与分配”选择备用模型并保存，可关闭自动切换。未指定时自动选择另一服务商且具备所需能力的已保存模型；无可用备用时返回原错误。

超时、429、5xx 和连接故障最多切换一次。权限取消、401/403、参数错误、输出过大等不触发切换。图片/视频与文档请求检查备用模型的图片输入/工具能力。后台日志记录来源模型、备用模型及安全的原因分类，不写 API Key。成功调用的费用按实际模型和 API 渠道计入，失败请求如已被上游计费仍需以官方账单为准。无限超时请求只有返回错误后才能切换。

通知和推送默认关闭。运行环境安装项目依赖后才能发送 SMTP 邮件；交付包首次启动仍可不安装邮件依赖。

### 复用已保存邮箱与手动发送

“QQ 连接 → 邮箱与通知”直接显示已保存的收件邮箱、SMTP 发件账号及配置状态。完整配置默认收起，通过“修改邮箱”展开；修改通知开关或发送时间时不必重填邮箱。授权码不回显，留空或不提交都保留原值；更换 SMTP 主机、账号或 TLS 连接方式时仍须输入新授权码。

“手动发送账单”可选本周截至当前或上周完整账单，使用服务端已保存的配置，不接受请求指定任意收件人。不依赖每周自动发送开关，不影响定时任务的周期去重；页面有未保存修改时需先保存。发送过程串行处理，两次手动发送至少间隔 30 秒，最近结果持久化显示。成功表示邮件服务已接受发送请求，实际收件状态以邮箱服务为准。


### 低饱和 C 版邮件与折叠图表

邮件采用低饱和雾灰、暖白和鼠尾草配色，搭配达妮娅立绘，主体只显示参考消费、Token、API 请求、API 渠道汇总及数据更新时间、官方基准校准时间。这里的消费对应筛选周期内的本地费用记录；不会把无法按日期拆分的官方总额基准摊到每天。

输入、输出、缓存命中、历史未拆分 Token 和两幅趋势图均放进 `details` 折叠区。左侧为每日 API 请求面积图，右侧为未命中输入、缓存输入、输出和未拆分 Token 的堆叠柱图。图表和立绘使用 CID 图片附件，读取邮件时无需访问 VPS 图片地址；生成图表失败时保留数字明细。邮箱不支持折叠标签时可能直接展开内容，实际显示以客户端为准。

手动发送前可选择全部或单个 API、上周、本周或自定义日期，范围最多 93 天且不能晚于今天。筛选同时作用于汇总、渠道表、明细和图表；邮件内不执行筛选脚本。定时每周邮件仍统计上周全部 API。美元费用沿用项目参考汇率，工具调用计入次数和费用但不增加 Token。
