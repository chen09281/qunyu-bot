# Card emoji font

`NotoEmoji.ttf` is the scalable monochrome Noto Emoji variable font from Google Fonts, downloaded on 2026-11-01. It renders musical notes and joined emoji sequences at card font sizes without relying on operating-system font locations or fixed bitmap strikes.

- Source: https://github.com/google/fonts/tree/main/ofl/notoemoji
- Download: https://cdn.jsdelivr.net/gh/google/fonts@main/ofl/notoemoji/NotoEmoji%5Bwght%5D.ttf
- SHA-256: `de6c18832938afc99caf132b39d6a30a19bac7f2e812e28db2535b4608d27551`
- License: SIL Open Font License 1.1, reproduced in `OFL-NotoEmoji.txt`.

The font is loaded offline by `src/link-worker.py`; it is included in Docker and source releases with the rest of `src/`.
