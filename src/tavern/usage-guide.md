# 一 什么是酒馆角色扮演

酒馆（SillyTavern）角色扮演功能支持在 QQ 群聊与已授权私聊中，直接导入 TavernAI / SillyTavern 社区标准角色卡（PNG 卡片与 JSON 角色文件）及世界书（Lorebook / Character Book），让机器人以完整角色设定、开场白、对话示例和世界观知识库与成员互动。

**核心特性**

- **兼容主流角色卡格式**：支持 TavernAI / SillyTavern V1、V2、V3 规范的 PNG（内嵌 `chara` / `ccv3` 元数据）与 JSON 文件。
- **世界书自动触发**：对话中命中角色卡内置世界书关键词时，自动将对应条目注入上下文提示词，无需手动重复科普设定。
- **群聊与私聊独立绑定**：每个 QQ 群、每位私聊用户可分别绑定并切换不同角色，对话记忆互不干扰。
- **独立 SillyTavern 容器（可选）**：管理员可在后台「插件 → 酒馆（SillyTavern）容器」中一键启停独立 WebUI 容器，用于在线编辑角色卡与管理复杂世界书。

# 二 管理员后台配置步骤

使用酒馆功能前，需由管理员在控制台完成以下准备：

1. **导入角色卡**：进入控制台左侧「工作空间 → 酒馆角色」，点击右上角「导入角色卡 (PNG / JSON)」上传角色文件。
2. **启用酒馆模式**：在页面顶部状态栏点击「启用酒馆模式」。启用后，机器人将优先以当前绑定的酒馆角色设定和提示词回应消息。
3. **设置默认角色**：在角色卡列表中点击「设为默认」，未单独绑定角色的群聊或私聊将自动使用该默认角色。
4. **微调设定与世界书**：点击角色卡的「详细设定」，可在线修改角色名称、开场白（支持 `{{char}}` 与 `{{user}}` 宏）、性格、情景、对话示例及后置指令。
5. **授权群聊与私聊**：确认目标 QQ 群已在「白名单」中启用，私聊用户已在「私聊白名单」中授权。

# 三 QQ 聊天快捷指令速查

在已授权的 QQ 群聊或私聊中，直接发送以下指令即可（无需 `@机器人`）：

| 指令 | 别名 | 作用说明 |
| --- | --- | --- |
| /酒馆 帮助 | /酒馆、/酒馆 help、/char help | 发送酒馆功能使用说明长图 |
| /酒馆 文档 | /酒馆 doc、/char doc | 发送本 PDF 使用说明文档 |
| /酒馆 列表 | /char list、/角色 列表 | 查看当前已安装的所有角色卡及使用状态 |
| /酒馆 切换 角色名 | /char switch、/角色 切换 | 为当前群或当前私聊切换指定角色（支持角色名或 ID 前缀） |
| /酒馆 信息 | /char info、/角色 信息 | 查看当前生效角色的头像、简介、性格与情景 |
| /酒馆 重置 | /char reset、/角色 重置 | 清空当前会话历史记忆，并重新发送角色开场白 |
| /酒馆 撤回 | /undo、/撤回 | 撤回上一轮机器人的角色回复 |
| /酒馆 重试 | /retry、/重试 | 撤回上一轮回复并提示上一轮提问内容，方便重新生成 |
| /酒馆 ooc 指令 | /ooc 指令 | 发送场外导演指令（Out of Character），指导接下来的回复口吻或剧情走向 |

**提示**

- 执行 `/酒馆 切换 <角色名>` 时，系统会自动清空当前会话的历史记忆，并发送新角色的开场白，避免旧角色上下文串台。
- 若群内多人同时与机器人互动，各成员在群内的对话记忆按 QQ 账号独立记录。

# 四 常见问题与排错

**1. 发送 `/酒馆 帮助` 或对话没有反应**

请管理员检查：① 机器人是否已开启；② 当前群是否在「白名单」中且已开启对话；③ 若为私聊，发送者 QQ 是否已加入「私聊白名单」。

**2. 机器人回复的还是普通助手，没有进入角色扮演**

请确认在控制台「酒馆角色」页面顶部已点击「启用酒馆模式」，并且已至少导入一张角色卡、设置了默认角色或在当前群执行过 `/酒馆 切换`。

**3. 导入角色卡提示格式错误或解析失败**

部分社区图片经过社交软件压缩后，PNG 文件内的 `chara` 元数据块会被清除。请重新下载未压缩的原图 PNG，或直接导入 `.json` 格式的角色卡文件。

**4. `/酒馆 文档` 无法上传文件**

请检查机器人在当前群是否有上传群文件权限，或群文件空间是否已满；白名单用户也可在私聊中发送 `/酒馆 文档` 获取教程。
