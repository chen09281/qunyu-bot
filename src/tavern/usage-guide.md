# 酒馆角色扮演使用说明

## 一 什么是酒馆角色扮演

群屿内置了**酒馆（SillyTavern）角色扮演引擎**。管理员可在管理后台直接导入社区 TavernAI / SillyTavern 角色卡（PNG 与 JSON）及内嵌世界书（Lorebook），无需额外部署外部酒馆容器，即可在已授权的 QQ 群聊与私聊中让机器人化身对应角色与成员交流。

### 核心能力一览

- **兼容标准角色卡**：支持读取 PNG 图片内嵌的 `chara` 元数据（原图同时存为角色头像），以及 TavernAI V1 与 SillyTavern V2（`chara_card_v2`）格式的 JSON 文件。
- **世界书自动激活与宏替换**：结合当前发言与最近 6 条历史扫描关键词与常驻条目；全面支持 `{{char}}`、`{{user}}`、`<BOT>`、`<USER>`、`{{scenario}}` 等宏变量。
- **按角色隔离的记忆空间**：同群切换不同角色时，后台按角色独立存储对话历史，旧角色上下文不会混入新角色人设。
- **五维情绪羁绊与动态关系**：后台静默记录好感度、愉悦度、信任度、紧张度、抑郁值 5 项情绪（`0–100`），按好感推进关系阶段；支持「全群共享」或「群友个人独立」两种计分模式。
- **情绪触发彩蛋与表情包**：为角色设置情绪阈值条件后，达到阈值会自动唤醒隐藏口癖或彩蛋设定，并在满足冷却轮数时附带发送自定义表情贴纸。
- **专属互动玩法**：支持 `/情绪` 查看五维雷达档案卡、`/羁绊榜` 排行、`/投喂` 送礼、`/剧场` 跨角色对戏，以及 `/ooc` 临时导演指令与 `/撤回`、`/重试` 状态回滚。

## 二 启用与后台配置指南

所有功能由管理员在群屿 Web 控制台的**「插件 → 酒馆角色扮演」**页面完成配置：

1. **导入角色卡**：点击右上角「导入角色卡 (PNG / JSON)」导入单张卡片（PNG ≤ 15 MiB），支持点开「详细设定」在线修改开场白、外貌、性格、对话示例、系统提示词与后置指令。
2. **设置默认与分会话绑定**：将常用卡设为「默认角色」，还可在「分群专属角色绑定」与「私聊专属角色绑定」指定不同群或好友的专属接待角色（优先级：私聊绑定 > 群绑定 > 全局默认角色）。
3. **选择好感度计算模式**：在顶部状态栏选择「全群共享」或「群友个人独立」。若想在群里开启 `/羁绊榜` 排行，推荐选择**群友个人独立**。
4. **配置情绪触发与表情包（可选）**：打开角色的「情绪指标」，可点击「导入常用模板」或自定义条件，并上传 PNG / JPEG / GIF / WebP 表情贴纸（单张 ≤ 4 MiB）。
5. **开启酒馆模式**：点击页面顶部「启用酒馆模式」，并确认机器人总开关、群聊白名单（需勾选 AI 回复）或私聊白名单已放行目标对象。

## 三 QQ 聊天指令速查

所有酒馆指令**必须以 / 或 # 开头**（例如 `/情绪` 或 `#情绪`）；不带前缀的普通聊天不会被误拦截。若后台已关闭酒馆模式，仅 `/酒馆`、`/tavern`、`/char`、`/角色` 会提示未启用，不抢占普通群聊。

## 四 情绪羁绊与互动玩法详解

### 1. 五项情绪指标与五个关系阶段

每次日常对话或投喂礼物后，系统会在后台静默根据互动氛围微调以下五项指标（取值 `0–100`，单轮增减限幅 `-10` 至 `+10`）：

- **好感度**（初始 `50`）：反映亲近与喜爱程度，直接决定关系阶段。
- **愉悦度**（初始 `60`）：心情开心明朗程度，数值偏低时角色会更安静或略显勉强。
- **信任度**（初始 `50`）：是否愿意向你敞开心扉或分享秘密。
- **紧张度**（初始 `20`）：感受到的戒备或心理压力，偏高时语气更谨慎。
- **抑郁值**（初始 `15`）：积累的失落或伤感情绪，被温柔陪伴后逐渐回落。

关系阶段按好感度递进：**0–19 疏离戒备** → **20–39 礼貌客套** → **40–59 普通熟人** → **60–79 亲近信赖** → **80–100 深度羁绊**。

### 2. 全群共享与个人独立好感度

- **全群共享模式**：群内所有人共享同一份角色情绪印象，发 `/羁绊榜` 会提示当前为共享模式。
- **群内个人独立模式**：群内每位成员拥有独立的雷达档案与好感度，可用 `/羁绊榜` 查看同群排名（私聊始终按好友个人独立计算）。

### 3. 投喂、小剧场与状态回滚

- **投喂玩法**：输入 `/投喂 草莓大福` 后，角色会结合人设品尝收下并改变好感度，命中条件时附带发送表情包。
- **小剧场玩法**：库中至少有 2 张卡即可开演；发 `/剧场 角色A 角色B 主题` 指定双角，只填主题时自动由当前角色与另一位角色搭档。
- **后悔药（撤回 / 重试）**：对上轮回复不满意时，发 `/撤回` 或 `/重试` 会同步把情绪还原到上一轮快照（最多保留 10 轮快照）。

## 五 角色卡制作与联动提示

- **宏变量替换**：在 `first_mes`、`mes_example` 或世界书正文写入 `{{user}}` 与 `{{char}}`，群聊时会自动替换为真实发言昵称与角色名。
- **世界书精准触发**：长设定建议放进 `character_book` 并设置主、次关键词；仅核心设定勾选 `constant` 常驻以节省上下文。
- **后置指令调风格**：若回复过长或抢台词，可在后台编辑卡面的「即时后置指令」补充简短约束。
- **定时问候与骰娘**：开启定时群聊时，机器人会按各群绑定角色口吻主动打招呼；娱乐骰娘 `.r` 亦可附带当前角色的短评吐槽。

## 六 常见问题排查（FAQ）

**问：群里发送 撤回、情绪 或 列表 为何没有反应？**
答：所有酒馆指令必须携带 `/` 或 `#` 前缀（如 `/情绪`、`#撤回`），并确认：1）机器人总开关与群白名单已开启；2）后台酒馆模式已启用；3）指令内不要混发图片或 `@` 无关群友。

**问：切换角色后，原本那位角色的聊天记忆会丢失吗？**
答：不同角色的聊天历史按角色隔离保存。不过**发起切换或重置的成员本人**会清空当前会话与目标角色在本作用域的情绪，以便用新印象重新开场；群友各自的旧角色记忆不会串线。

**问：发送 羁绊榜 为什么提示目前使用全群共享好感度？**
答：后台当前设置为「全群共享」，让管理员在「插件 → 酒馆角色扮演」顶部下拉切换为「群友个人独立」即可开启排行榜。

**问：切换角色没有头像、情绪只有文字，或导出 PDF 失败怎么办？**
答：仅上传自带 `chara` 数据的 PNG 角色卡会保留原图头像；`/情绪` 档案卡、`/酒馆 帮助` 长图与 PDF 文档依赖 Chromium 渲染组件，使用 Docker 一体化部署即可完整支持。全部卡片、头像、表情贴纸与好感数据保存在 `data/tavern/` 目录，迁移前完整备份 `data/` 即可保留。
