# 签到账号绑定教程

森空岛 · 米游社 · 库街区

先在授权群开通，再私聊绑定自己的账号。每个 QQ 可绑定三个平台各一个账号；只需阅读你要绑定的平台章节。

# 快速开始

## 1 在群内开通

在管理员已授权的群里发送下面这条命令，**无需 @ 机器人**。

```text
/签到 开通
```

## 2 加好友并私聊绑定

加机器人为好友，按对应章节获取凭据，再把**完整绑定命令作为一条私聊消息**发送。

| 要绑定的平台 | 需要什么 | 阅读章节 |
| --- | --- | --- |
| 森空岛 | 官网登录后取得的 token | 森空岛绑定 |
| 米游社 | 包含登录令牌与账号 ID 的 Cookie | 米游社绑定 |
| 库街区 | 库街区 App 的 token | 电脑 安卓或 iOS 章节 |

## 3 确认成功后测试签到

收到“绑定成功”后，私聊发送 `/签到`，再用 `/签到 状态` 查看结果。

**绑定成功不代表当天已签到。** 新开通成员默认开启自动签到，时间由管理员设置，按北京时间执行。

## 发送凭据前请检查

- **凭据只发私聊**，不要发到群里、截图或公开链接。不要发送账号密码或短信验证码。
- 示例中的 `YOUR_TOKEN`、`YOUR_COOKIE_TOKEN` 和数字都是占位内容，请换成自己的真实值。
- Cookie 和 token 都能代表登录身份。只向可信的机器人提交自己的凭据；服务器管理者仍可访问保存的数据。

发送 `/签到 帮助` 查看帮助图片，发送 `/签到 文档` 获取本教程。

# 森空岛绑定

**需要准备：** 已登录自己鹰角账号的电脑浏览器。

## 1 登录森空岛官网

打开 [森空岛官网](https://www.skland.com/)，完成登录，确认显示的是自己的账号。

## 2 在同一浏览器获取 token

保持登录，在同一浏览器、同一会话中新开标签页，打开 [森空岛账号信息接口](https://web-api.skland.com/account/info/hg)。

页面会显示 JSON 文本。找到 `data` 里的 `content`，**复制 content 的值，去掉两侧引号**。

只看字段位置，示意如下：

```json
{"data":{"content":"YOUR_TOKEN"}}
```

## 3 私聊发送绑定命令

将 `YOUR_TOKEN` 换成刚才复制的值：

```text
/签到 绑定 森空岛 YOUR_TOKEN
```

也可以在 `/签到 绑定 森空岛 ` 后直接粘贴接口返回的完整 JSON，机器人会自动读取 `data.content`。

## 4 确认结果

收到“绑定成功”后，发送 `/签到` 测试，发送 `/签到 状态` 查看记录。

**取不到 content：** 回官网重新登录，再打开接口。不要复制错误页面。换账号时使用独立的浏览器会话，避免拿到原账号的 token。

**容易混淆：** 网页地址、游戏 UID、cred 和 Cookie 都不能代替这里的 token。

参考：[skyland-auto-sign 使用说明](https://github.com/YueHen14/skyland-auto-sign)。

# 米游社绑定

**需要准备：** 电脑 Chrome 或 Edge、自己的米游社国服账号。仅有 `ltoken` 不够，HoYoLAB 海外服 Cookie 不适用。

## 1 登录并打开网络面板

在无痕窗口打开 [米游社官网](https://www.miyoushe.com/ys/) 并登录。按 **F12** 或右键“检查”，选择 **Network（网络）→ Fetch/XHR**。Mac 可按 Option + Command + I。

## 2 找到登录请求中的 Cookie

筛选 `getUserGameUnreadCount`，刷新或进入个人页面触发请求。点击该请求，依次打开：

**Headers（标头）→ Request Headers（请求标头）→ Cookie**

复制 Cookie 后面的完整值，**不要带 `Cookie:` 前缀**，不要复制 Set-Cookie、整个请求或 cURL 命令。

如果页面暂停，到 Sources（源代码）停用断点并恢复运行。筛选无结果时，清空筛选，检查其他米游社登录请求的 Cookie。

## 3 检查字段并私聊绑定

| Cookie 字段 | 常见名称 |
| --- | --- |
| 登录令牌 必须有 | cookie_token_v2 或 cookie_token |
| 账号 ID 必须有 | account_id_v2 或 account_id；也接受 ltuid_v2 或 ltuid |

以下是最小格式示例。把数字和令牌换成自己的值，保留英文分号和等号，**整条命令不要人为换行**。

```text
/签到 绑定 米游社 account_id_v2=123456789; cookie_token_v2=YOUR_COOKIE_TOKEN
```

完整 Cookie 可以有更多字段，但必须来自同一账号。缺少登录令牌时请重新登录后获取，不要用空值或 `ltoken` 补齐。

## 可选 开启社区签到

**只要游戏签到，可以跳过本节。** 没有 `stoken` 时，游戏签到照常执行，社区签到会显示缺少凭据并跳过。

需要社区签到时，可参考 [mihoyo_login](https://github.com/Womsxd/mihoyo_login)，在自己的设备获取同一账号的字段，追加到 Cookie 后重新绑定：

```text
; stoken=YOUR_STOKEN; stuid=123456789
```

若 stoken 以 `v2_` 开头，还需追加 `; mid=YOUR_MID`。网页 Cookie 未必包含 stoken，不能用 ltoken 代替。

参考：[MihoyoBBSTools 的 Cookie 说明](https://github.com/Womsxd/MihoyoBBSTools#获取米游社-cookie)。

# 库街区电脑获取与绑定

**需要准备：** 自己的库街区账号、能接收短信的手机，以及 Python 3.10 或更新版本。

## 1 下载本机获取工具

打开 [库街区 Token 工具下载页](https://bot.example.com/tools/kuro/)，选择“电脑本机版”。

下载地址：`https://bot.example.com/tools/kuro/`

**这是 Python 源码工具包，需要本机 Python，不是 Windows 免安装 EXE。** 手机号、验证码和 token 在本机处理，请勿提交到下载页或群聊。

## 2 解压并启动

- Windows：解压整个 ZIP，双击 `启动.bat`。
- macOS 或 Linux：在解压目录执行 `python3 kuro_token.py`。
- 工具会打开浏览器中的本机页面；没有自动打开时，复制终端显示的本机地址到浏览器。

## 3 官网领短信后回工具获取

点工具里的“打开库街区官网”，打开登录，点击获取验证码并手动完成人机验证。

**收到短信后不要点击官网登录。** 回到本机工具，输入同一手机号和验证码，确认新登录可能使 App 旧会话失效，再点获取。

工具直接向库街区官方 HTTPS 接口换取 App token；不自动发短信、不自动通过验证码，也不把账号数据发给 VPS。

## 4 复制完整命令并绑定

成功后点“复制绑定命令”，只发到机器人私聊。命令大致如下，占位内容必须换成自己的实际值：

```text
/签到 绑定 库街区 {"token":"YOUR_TOKEN","userId":"123456789","devCode":"YOUR_DEV_CODE"}
```

userId 是库街区社区用户 ID，不是鸣潮或战双角色 UID。已有原始 token 时也可私聊 `/签到 绑定 库街区 YOUR_TOKEN`。

收到机器人“绑定成功”后，再发送 `/签到` 测试。工具获取成功不代表机器人已经绑定。退出工具时，在终端按 Ctrl+C。

**登录被拦截或验证码过期：** 回官网重新领取，勿先消耗验证码；仍被风控拦截时停止重试，使用下一页说明中的已有 App 响应提取方式。

# 库街区安卓 App 获取与绑定

**适用：** Android 8.0 及以上。不需要电脑、Python 或额外脚本 App。

## 1 下载并安装

在手机浏览器打开 [库街区 Token 工具下载页](https://bot.example.com/tools/kuro/)，选择“安卓 App”，下载 APK。

按系统提示允许当前浏览器安装此应用，完成后打开“库街区 Token 工具”。如果下载页提示安装包尚未构建，请联系管理员。

## 2 官网领取验证码

点 App 中的“打开库街区官网”，在浏览器打开登录，手动完成人机验证并领取短信。

**收到短信后不要点击官网登录。** 返回工具 App，输入同一手机号和刚收到的验证码。

## 3 获取并复制绑定命令

勾选“新登录可能使 App 旧会话失效”，再点“获取 token 并生成命令”。

成功后点“复制绑定命令”，到 QQ **私聊机器人**粘贴整条命令，等待“绑定成功”。再发送 `/签到` 测试，签到结果会显示游戏内昵称／角色名，例如“鸣潮 · 小团子：签到成功”。

## 已有 App token 时离线提取

在 App 下方粘贴自己取得的完整登录响应 JSON 或原始 token，点“提取绑定命令”。此方式只在本地解析，不请求网络，也不验证登录是否有效。

userId 是库街区社区用户 ID，**不是游戏 UID**。不要复制 refreshToken、鸣潮游戏登录 token 或抽卡记录链接。

## 验证失败与隐私

- 验证码过期：回官网重新领取，勿先在官网消耗；官方风控拦截时停止重试，使用已有 App 响应提取。
- App 仅需要网络权限，不读取短信、通讯录或其他 App 的账号。手机号与验证码直连官方 HTTPS，不发送到 VPS。
- 不保存输入或账号文件；退出前可点“清空本页凭据”。复制后的命令会留在系统剪贴板，请勿粘贴到群里。

# 库街区 iOS 获取与绑定

**适用：** iPhone 和 iPad。iOS 不能直接运行电脑 Python 包，请使用 Scriptable 本地脚本，不需要安装抓包证书或描述文件。

## 1 安装 Scriptable 并获取脚本

从 App Store 安装 [Scriptable](https://scriptable.app/)。在 Safari 打开 [工具下载页](https://bot.example.com/tools/kuro/)，下载 iOS 脚本。

也可展开下载页的“完整 iOS 脚本源码”，复制文本框内全部内容；在 Scriptable 点加号，新建脚本、粘贴并保存。

## 2 领取短信并获取 token

- 在 Scriptable 内运行脚本，选择“用官网短信验证码获取”。不要在小组件里运行。
- 在打开的库街区官网领取短信，手动完成人机验证；**收到短信后不要点官网登录**。
- 点“完成”回工具，输入同一手机号和验证码，确认登录。
- 成功后点“复制绑定命令”，到 QQ 私聊机器人粘贴，等待“绑定成功”。

脚本直接请求库街区官方 HTTPS 接口，不向 VPS 传输手机号、验证码或 token，不保存凭据。重新登录可能导致 App 旧会话失效。

## 3 已有 App 登录态时直接提取

希望共用现有 App 会话，或短信方式被官方拦截时，可以复制自己取得的登录响应 JSON。在脚本选择“从剪贴板中的响应提取”。电脑工具也提供已有响应提取入口。

**提取只解析文本，不发网络请求，也不验证登录是否仍有效。** 以机器人实际绑定回执为准。

若通过 iOS HTTPS 调试工具查看自己的 App 请求，只针对 `api.kurobbs.com`：查找库街区 App `/user/sdkLogin` 的响应 `data.token`，或官方请求头中的 `token`。不要复制 `refreshToken`、鸣潮游戏登录 token 或抽卡记录链接。

App 可能阻止解密，不能保证抓包可用。完成后停止调试并清理记录；临时启用的代理与证书信任也应关闭。工具不会绕过平台风控或验证码。

## 登录失效时

重新登录或换设备可能使旧 token 失效，请重新获取后绑定。只需自己的 token；不要捏造 userId 或 devCode，不要把凭据发到群聊。

# 命令速查与常见问题

## 常用命令

| 命令 | 用途与发送位置 |
| --- | --- |
| /签到 | 立即签到；群聊或私聊 |
| /签到 状态 | 查看自己的绑定与结果；群聊或私聊 |
| /签到 自动 开 | 开启自己的每日签到；群聊或私聊 |
| /签到 自动 关 | 暂停自己的每日签到；群聊或私聊 |
| /签到 解绑 森空岛 | 删除该平台凭据；仅私聊，平台名可替换 |
| /签到 解绑 全部 | 删除自己的全部签到记录；仅私聊 |
| /签到 帮助 | 查看一张帮助图片；群聊或私聊 |
| /签到 文档 | 获取详细 Word 教程；群聊或私聊 |

## 遇到问题时这样处理

**提示先开通或无法确认群成员**

回授权群发送 `/签到 开通`。仍失败时，请管理员检查群白名单和 QQ 连接。

**格式错误或绑定失败**

检查平台名、凭据是否完整、有无中文引号或额外换行。绑定失败不会覆盖此前账号。

**登录已过期 或 需要验证码**

到官方网页或 App 登录、完成验证，必要时获取新凭据并重新绑定，再手动签到。过期账号会暂停自动任务；机器人不会自动通过验证码。

**没有角色 或 社区签到被跳过**

先在官方平台绑定游戏角色；米游社社区被跳过时检查 stoken，游戏签到结果单独查看。

**收不到教程文件**

检查群文件权限或空间，也可加机器人好友后私聊 `/签到 文档` 重试。

**凭据误发群聊**

尽快撤回，通过官方安全入口注销相关会话或更新凭据，再私聊解绑并重新绑定。**解绑只删除机器人数据，不会注销平台登录态。** 插件暂停后仍可私聊解绑。
