库街区 Token 工具

本机版 1.1.0 · 手机号与验证码直连库街区官方 HTTPS 接口 · 不保存登录数据

方式一 用短信验证码获取

先到官网点击获取验证码，手动完成人机验证，收到短信后不要点击官网登录，回本页输入。

打开库街区官网

本工具不自动发送短信、不自动解验证码。若官方拦截此方式，使用下方已有响应提取。

方式二 从已有登录响应提取

粘贴自己已取得的 App 登录响应 JSON，或原始 token。本方式只解析本地内容，不发送网络请求。

绑定命令已生成

只发送给机器人的私聊。提取成功不代表账号已绑定，以机器人回复为准。

关闭终端可停止本机服务。不要把 token 放到群里或截图公开。
